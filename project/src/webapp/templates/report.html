Classification Logic

Voice / Video Calls

Identified via UDP streams on dynamic high ports (>1024) exceeding VoIP bitrate thresholds (12kbps for voice, 50kbps asymmetric for video) following a STUN binding handshake.

Media Transfers (Photo/Audio)

Identified via TCP port 443 (TLS) utilizing SNI prefixes like mmi or mms (media servers), often characterized by sudden burst transfers.

Chat Messaging

Identified via persistent TCP connections on ports 5222, 5223, or 4244 characterized by small, intermittent encrypted frames (Noise/XMPP protocol).

Classification Legend

  • Call Relay (TURN): Meta/Facebook ASN UDP port > 1024. This is a relay server, NOT the actual peer. Location is a data center.
  • WhatsApp Chat Server: Meta ASN TCP port 443/5222/5228. Messages transit via WhatsApp's infrastructure.
  • WhatsApp Media CDN: Meta ASN TCP port 443. CDN edge for media delivery.
  • Direct Peer: Non-Meta IP on call-type port. Location is likely the other caller's ISP exit.
  • Caveated (VPN/CGNAT): Location is unreliable; party is behind a VPN, CGNAT, or uses a Private IP.

Geolocation Caveat

WhatsApp uses CDN edge nodes to route traffic. The country listed reflects the location of the Meta/Facebook server handling the traffic, not necessarily the physical location of the other person in a chat, unless the connection was established peer-to-peer (P2P).
